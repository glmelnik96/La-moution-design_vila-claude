## Файлы и сборка

```
index.html, deck.css, deck.js     презентация (deck.js: рантайм + 8 слайдов, у каждого свой таймлайн lib/motion.js;
                                  у ×5 — второй, перенос со слайда 1; у фильтра — idle-цикл битов)
img/*.webp                        фото-слои: такси, куб, салон — tools/prep_assets.py; стойки и бык — tools/prep_v2.py
                                  (бык: фильтры Figma «saturation −1, exposure» запечены 3D-LUT, слой screen 90 %)
fonts/manrope.woff2               Manrope 400–700 — одно подмножество Google Fonts ровно под глифы колоды
ref/                              рендеры Figma нового макета 1:1 — эталон финальных кадров (ref_v1/ — старого)
tools/build_single.py             один самодостаточный HTML → out/gocloud-tech-2026/GoCloudTech2026_v2.html
                                  (картинки берёт из таблицы IMG в deck.js)
tools/shoot.sh                    кадры через html/render/render.js (rest / beats / sheet)
tools/compare.py, tools/zoom.py   сверка финальных кадров с Figma
tools/navtest.js                  прогон «как докладчик»: стрелки, перенос, назад, цифра, двойной клик, R,
                                  поток битов на фильтре, ошибки консоли
```

Хуки рендера: `?render&slide=N[&fresh][&idle=S][&outidle=S]` — один слайд как клип (`idle` — секунды
потока битов после сборки, `outidle` — сколько он шёл у уходящего слайда, чтобы клипы стыковались без скачка);
`?slide=N&t=T|end` — замороженный кадр.

Не в git (правило репозитория: *.png игнорируются): `ref/`, `ref_v1/`, `ref2/` (рендеры Figma, `get_screenshot`
2304 px) и `assets/raw*/*.png` (экспорты и исходники картинок, `download_assets`) — вход для `prep_*.py` и сверки,
качаются из Figma заново. Страница работает без них: ей нужны только `img/*.webp`, `fonts/`, `lib/`.

Сверка финальных кадров с Figma (mean |diff| / 255): 1 — 0.42, 2 — 1.03, 3 — 4.08 (воронка пересобрана векторно
намеренно), 4 — 0.36, 5 — 0.41, 6 — 1.48 (сглаживание чёрного текста на белом; центроиды строк — в пределах
0.2 px), 7 — 0.53, 8 — 2.30. Строки текста — 0/−1 px от рендера Figma; «в год» и «тысяч лет» (градиентный
текст с дробной высотой строки 59.4) — ±0.5 px. Ни одна строка не вылезает из своей плашки (аудит вёрстки).
