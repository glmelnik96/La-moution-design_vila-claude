# HTML5 display packages

Check the current media-platform documentation for each slot. Confirm dimensions, file and ZIP
limits, runtime behaviour, click parameters, legal markings and acceptable external dependencies.
Where the platform supports macros for click-through or a script nonce, preserve their literal
format from its documentation. Confirm whether each rule applies to HTML, embedded video or
an image fallback.

Use one runtime with build data for each supported layout. Give fixed slots explicit dimensions.
For fluid placements, test the supported widths and breakpoints, including fractional device
scales. Keep required markings visible in every frame, including the first frame and the loop seam.
Verify image fallbacks separately against the allowed size and density.

Open the final archive in a clean test page. Check autoplay, click area, console errors, visual
rest states and the loop seam. Measure the HTML and ZIP against their own limits. Validate
local fonts and assets in an offline test when the platform requires a self-contained package.
