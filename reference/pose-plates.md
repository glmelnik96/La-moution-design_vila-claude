# Лист поз персонажа и сменные фоны

Используйте этот маршрут для перекладки, аниматика или теста стыка, когда один герой повторяется в нескольких планах. На выходе остаются прозрачные изображения поз, отдельные фоны и покадровая экспозиция. Тайминг, фоны и крупность можно менять независимо.

## Подготовка слоёв

1. Выберите по исходной сцене одно понятное действие. Запишите ID персонажа, порядок фаз, направление взгляда, сторону опоры и точные исходные кадры. Например, ботинок коснулся пола, колено сжалось, корпус поднялся. Запишите смену ракурса как смену камеры. Для раскадровки фазы действия нужны и внутри одного ракурса.
2. Возьмите слои из проекта либо подготовьте матт по кадрам с разрешённым для этой работы персонажем. Маскируйте просветы между руками, ногами и корпусом. Подготовьте PNG с настоящим альфа-каналом и прямым цветом; сохраняйте исходную плотность пикселей поз. Нужен отдельный чистый фон без первого экземпляра персонажа. В сцене с предметом разделите дальний фон, предмет и переднее перекрытие по глубине в композиторе.
3. Поставьте в локальных пикселях PNG точку регистрации `anchor` на одном и том же участке героя. Для стоящего героя годится точка контакта выбранной подошвы. Подпишите, какой это ботинок. Для сидящего героя это может быть точка контакта с сиденьем. При смене опорной ноги или прыжке задайте другую позу и положение. Сверьте силуэт на светлом и тёмном фоне. Свет, тень, отражение и перспективу выбранной пластины оцените отдельно по исходному кадру.

## Сборка просмотрового ролика

Из корня скилла запустите Python с Pillow и доступным в PATH FFmpeg. Передайте новую папку вывода. Файлы в манифесте указываются относительно самого манифеста, координаты и кадры считаются от нуля.

```powershell
python scripts/pose_plates.py scene.json --out review/pose-v01
```

```json
{
  "size": [960, 540], "fps": 24,
  "poses": [
    {"id": "bend", "label": "Колено согнуто", "file": "poses/bend.png", "anchor": [32, 141]},
    {"id": "stand", "label": "Корпус выпрямлен", "file": "poses/stand.png", "anchor": [30, 170]}
  ],
  "plates": [{"id": "floor", "file": "plates/floor.png"}],
  "shots": [
    {"id": "wide", "plate": "floor", "at": [360, 426], "scale": 1,
     "exposures": [{"pose": "bend", "frames": 8, "contact": true}]},
    {"id": "medium", "plate": "floor", "plateView": [96, 48, 768, 432],
     "at": [330, 473], "scale": 1.25,
     "exposures": [{"pose": "bend", "frames": 2, "contact": true},
                   {"pose": "stand", "frames": 12, "contact": true}]}
  ]
}
```

- `size` задаёт чётные размеры MP4, `fps` — частоту кадров целым числом или точной дробью в строке, например `"24000/1001"` или `"30000/1001"`. `frames` задаёт экспозицию каждой позы. Переносите точный ритм из исходного футажа либо задавайте осознанные удержания для перекладки. MP4 предназначен для визуальной проверки при этой частоте и собирается без звука.
- `at` — положение точки регистрации в пикселях результата. Его можно переопределить в конкретной экспозиции. `scale` масштабирует весь слой вокруг этой точки. При `contact: true` инструмент проверяет альфу в выбранной точке PNG. Контакт с полом, горизонт, мечущуюся тень и проскальзывание проверяйте по картинке. При прыжке или воздушном пивоте используйте `contact: false`.
- `plateView` — необязательный прямоугольник `[x, y, ширина, высота]` в исходной пластине. Соотношение сторон должно совпадать с `size`. При склейке на более крупный план перенесите опору тем же преобразованием, что и фон. Для намеренно срезанного крупного плана укажите `allowCrop: true` у этого плана.
- `poses.png` показывает альфу на шахматке и точки регистрации. `take.mp4` показывает стыки в реальном времени, `timing.json` хранит интервалы `[in, out)`, координаты и реальные границы каждого слоя. Для исправления одной фазы замените её PNG, для ритма измените `frames`, для нового окружения замените `plate`. Раздельные пути позволяют воспроизвести эти операции в AE как слои с hold-ключами или в seekable HTML.

При приёмке откройте последний кадр первого плана и первый кадр следующего. Сопоставьте высоту относительно горизонта, сторону опоры, силуэт и фазу движения. Во втором варианте оставьте тайминг и позы прежними при замене фона. При ретайме отдельно проверьте новую границу планов и финальный кадр. Наиболее заметные отверстия в маске смотрите в размере поставки. Результат приёмки привяжите к версии, ID плана и номеру кадра.
