## Файлы и сборка

```
index.html, deck.css, deck.js     презентация (deck.js: рантайм + 7 слайдов, каждый — свой таймлайн lib/motion.js)
img/                              фото-слои, вырезанные из экспортов Figma (tools/prep_assets.py)
fonts/                            Manrope (woff2, кириллица + латиница)
ref/                              рендеры Figma 1:1 — эталон финальных кадров
tools/build_single.py             один самодостаточный HTML → out/gocloud-tech-2026/GoCloudTech2026.html
tools/shoot.sh                    кадры через html/render/render.js (rest / beats / sheet)
tools/compare.py, tools/zoom.py   сверка финальных кадров с Figma
tools/navtest.js                  прогон «как докладчик»: стрелки, назад, цифры, ошибки консоли
```

Не в git (правило репозитория: *.png игнорируются): `ref/*.png` (рендеры Figma, `get_screenshot` 2304 px) и
`assets/raw/*.png` (экспорты и исходники картинок, `download_assets`) — вход для `prep_assets.py` и сверки, качаются
из Figma заново. Страница работает без них: ей нужны только `img/*.webp`, `fonts/`, `lib/`.

Сверка финальных кадров с Figma (mean |diff| / 255): 1 — 0.39, 2 — 4.7 (линии пересобраны намеренно),
3 — 0.36, 4 — 0.50, 5 — 1.66, 6 — 0.60, 7 — 2.30.
