# Cloud.ru — моушен-язык бренда (motion brand)

**Статус:** house style по умолчанию для этого скилла. Любая анимация — в AE или в HTML —
сначала проверяется на соответствие этому документу, потом на технику.
**Источники:** брендбук Cloud.ru 2.0 (Look & feel, палитра, типографика, портал, паттерны,
линейные иллюстрации), canonical-правила шаблона `Cloud.ru_Template_2026`, IBM Carbon motion
(как методологическая база «productive / expressive»), плюс живой опыт этого репозитория.
**Токены:** все числа ниже живут в `brand/cloudru-motion-tokens.json` и генерируются в оба
движка (`scripts/lib/tokens.jsx`, `html/engine/tokens.js|css`). Здесь — смысл, там — значения.

---

## 0. Одним абзацем

Cloud.ru — «устойчивая основа для движения вперёд». Это и есть формула моушена: **тяжёлая,
неподвижная основа + одно решительное движение вперёд.** Всё, что движется, движется по
осям, без дуг и без отскока; всё, что остановилось, стоит абсолютно неподвижно. Динамику
создают не «живость» элементов, а **ритм** (ступени портала, каскад паттерна, счётчик),
**контраст** (тёмный ↔ светлый кадр, 300 px цифра ↔ 20 px подпись) и **один зелёный акцент**,
который ведёт глаз. Бренд сильный и динамичный, профессиональный и уверенный — не игривый и
не «дышащий». Если анимация выглядит как реклама стартапа с пружинками — это не Cloud.ru.

## 1. Четыре закона движения

1. **Ось, не дуга.** Элементы входят и выходят строго по горизонтали или вертикали. Никаких
   траекторий по кривой, никаких поворотов, кроме 90°/180° шагов (портал можно
   «перевернуть», нельзя «покрутить»). Path-анимации — только прямые.
2. **Решительно и без отскока.** Вход — `enter` (`0.16, 1, 0.3, 1`): быстрый старт, тяжёлая
   посадка, ноль overshoot. Выход — `exit`, ускоряющийся, на 30% короче входа. Перемещение по
   экрану — `move`. Механические шторки и ступени — `wipe` (медленно-быстро-медленно, читается
   как механизм). Линейно — только конвейеры/тикеры.
3. **Покой абсолютен.** После посадки элемент не «дышит», не wiggle-ит, не плавает. Жизнь кадра
   держат: вход/выход, счётчик, ступенчатый паттерн, смена сцены. Idle-анимация допустима только
   у фонового паттерна (медленный дрейф точек ≤ 2 px/с) и у видео-контента.
4. **Один акцент на кадр.** Одна вещь движется «главной», остальное её поддерживает. Если в
   кадре одновременно летят заголовок, цифра и паттерн — вы сделали три кадра в одном. Разнесите
   во времени (stagger) или уберите.

## 2. Словарь брендовых движений

Все приёмы имеют реализацию в обоих движках: `reference/motion-vocabulary.md` (каталог с
указателями на рецепты), `reference/ae-cloudru-recipes.md` (AE) и `reference/html-engine.md` (HTML).

| Приём | Что это | Где уместно | Параметры по умолчанию |
|---|---|---|---|
| **Line reveal** | строка текста поднимается из-под маски (клип по строке), без размытия | заголовки, подзаголовки, body-блоки | `enter`, `base`/`slow`, stagger `base` между строками |
| **Slide-in** | блок въезжает по оси на 40–80 px с fade 0→100 | карточки, колонки, плашки, логотип | `enter`, `base`, stagger `base` |
| **Block wipe** | жёсткая прямоугольная шторка (зелёная/графитовая) проходит по кадру и уносит/приносит сцену | смена сцен, divider | `wipe`, `wipe` ms; край строго прямой |
| **Portal wipe** | шторка из N ступенчатых прямоугольников (портал = «повторение со сдвигом») — ступени идут одна за другой | divider, title, финал — «подпись бренда» | 4 ступени, stagger `tight`, `wipe` |
| **Portal build** | портал собирается из прямоугольников по одному (ступенька за ступенькой), HOLD-ключами или `steps()` | контейнер для изображения, логоблок | шаг 40 px, step-timing `tight` |
| **Count-up** | большая цифра считает от 0 (или от старого значения) до целевого, табличные цифры, tracking −0.03em | KPI, метрики, «199 pt»-приём | `count`, `count` ms; знак «%» появляется после числа |
| **Pattern build** | паттерн точек / сетки / ЛЛЛЛ появляется рядами или от акцента наружу | фон divider, финал, «технологичность» | размер 2/4/6, stagger `pattern_row` |
| **Grid draw** | сетка линий рисуется (trim path / clip) по осям, square caps | архитектурные схемы, техно-фон | линия 2 px, `enter`, `base` |
| **Rule / underline** | горизонтальная линия вырастает от 0 до 100% ширины слева направо | под заголовком, под колонкой, маркер шага | 2–4 px, `enter`, `fast` |
| **Scheme flow** | блоки схемы появляются в порядке чтения, стрелки *рисуются* между ними после появления обоих блоков | архитектуры, процессы | стрелки серые 2 px, `enter`, stagger `base` |
| **Cross-tone cut** | жёсткий монтажный стык светлый→тёмный (без перехода) на бит | ритм длинного ролика | hard cut, затем `enter` контента через 2–3 кадра |
| **Parallax push** | камера линейно едет вперёд ≤ 3% кадра за сцену; слои на разной глубине | премиум-титры, финал | `move`, линейный dolly, без орбит |
| **Arrow ✦ / cloud / star** | линейные иллюстрации рисуются по контуру (draw-on), ≤ 2 цветов | callout, AI-контекст (звезда), инфраструктура (облако) | 2/4/6 px, `enter`, `base` |
| **Step numbers** | «01 → 02 → 03» — номер шага сменяется вертикальным сдвигом под маской (одометр) | процессы, дорожные карты | `enter`, `fast` |
| **Code / terminal** | моноширинный текст печатается посимвольно, курсор — прямоугольник | только dev-контекст (единственное место для typewriter) | `chars` stagger, HOLD |

## 3. Хореография по типам сцен

Тайминги — в мс, `f()` переводит в кадры по fps композиции. `t=0` — начало сцены.

### 3.1 Title (титул)
```
0        ground: белый/графит — статичен (или hard cut с предыдущей сцены)
0–600    portal wipe открывает кадр слева направо (4 ступени, stagger 40)   ← подпись бренда
300      логотип: slide-in сверху 40 px, enter, 400
500      заголовок 132 px: line reveal по строкам, stagger 70, enter, 700
900      подзаголовок 42 px в зелёной плашке: плашка wipe слева 0→100% (wipe, 400),
         текст line reveal после плашки (+150)
1100     паттерн (ЛЛЛЛ или точки) в углу: pattern build, 30/ряд
hold     ≥ 2000
exit     всё уходит exit-ease за 400: заголовок вниз под маску, плашка wipe вправо, паттерн fade
```
Правило: заголовок — **action title** (сообщение, не тема), ≤ 3 строки, без висячих предлогов.

### 3.2 Divider (разделитель)
```
0        block wipe цветом divider (зелёный или графит) закрывает кадр за 600 (wipe)
400      цифра раздела (144 px) count-up или одометр 0→N за 500
600      заголовок раздела line reveal, 700
800      bracket-рамка рисуется: две линии от углов, enter 500
hold     ≥ 1500 ; exit: hard cut в следующую сцену на бит
```

### 3.3 KPI (большие цифры)
```
0        заголовок 66 px line reveal
300      три числа 300 px появляются slide-in снизу 40 px, stagger 120
300–1700 count-up каждого (count, 1400) — все стартуют одновременно, приходят в порядке слева направо
1700     знак «%» / единица 132 px slide-in справа после посадки числа
1900     подписи 20 px fade, stagger 70
2000     ОДНО число (главное) окрашивается в зелёный — не три; smooth colour cut за 200
hold     ≥ 2500
```
Только один зелёный акцент. Отрицательные KPI — не красные, а серые.

### 3.4 Content 3-col / 4-block
```
0        заголовок line reveal
300      колонки: slide-in снизу 40 px, stagger 120 (слева направо)
+200     под каждым колонкным заголовком — rule 0→100% (fast)
+350     body строки fade, без движения (текст 24 px не должен «ехать»)
```
Не более 35 слов на колонку; body появляется fade-ом, а не покадровым typewriter.

### 3.5 Callout / цитата
```
0        тёмный кадр hard cut
200      bracket-рамка draw-on (enter, 600)
400      текст 66 px line reveal, stagger 90
1200     зелёный маркер-квадрат (12×12) slide-in перед первой строкой
```

### 3.6 Scheme (архитектура / процесс)
```
0        заголовок
300      блоки в порядке чтения slide-in 40 px, stagger 100
+блок    стрелки рисуются trim-path 0→100 (серые 2 px, square caps) только после появления обоих концов
+finish  один блок выделяется зелёной обводкой 4 px (акцент) — 200
```

### 3.7 Logo finale
```
0        зелёный кадр (block wipe снизу вверх, 600)
400      логотип: portal build за ним (3 ступени графит 10%), логотип slide-in, enter 500
900      «Спасибо» 66 px line reveal; контакты 24 px fade
1400     паттерн точек внизу pattern build; затем полная неподвижность до конца
```

## 4. Типографика в движении

- **Маска по строке**, не по символу. Заголовок никогда не рассыпается на буквы.
- **Reveal вверх** — из-под нижней кромки строки (клип ровно по line box, 100% leading), без
  blur, без scale.
- **Цифры**: табличные, tracking −0.03em; счётчик меняет только цифры, единица и знак статичны
  и появляются после числа. Разделитель тысяч — узкий неразрывный пробел (U+202F), не запятая.
- **Никакого** italic / underline / mixed weight / letter-spacing-анимации на заголовках.
- Body-текст не двигается на большие расстояния (≤ 40 px) и не «печатается».

## 5. Цвет в движении

- Зелёный — **сигнал**: он либо приходит последним (акцент-цифра, маркер), либо служит
  шторкой перехода. Он никогда не является фоном content-сцены дольше, чем длится wipe.
- Смена тона — **hard cut или block wipe**, не cross-dissolve (dissolve = «мягко», не бренд).
- Один доп. цвет (yellow/purple/blue) — только вместе с зелёным, только в инфографике.
- Тёмных сцен ≤ 40% хронометража.

## 6. Геометрия и материал

- Углы прямые, `border-radius: 0`, линии с square caps и miter joins.
- Толщины линий 2/4/6 px; точки 2/4/6 px; всё кратно микромодулю 2 px; отступы от края кратны 10.
- Никаких теней, свечений, градиентов, зерна, motion-blur «как стиль». **Motion blur в AE** —
  допустим как физическая корректность на быстрых шторках (shutter ≤ 90°), **выключен** на
  заголовках и HOLD-ключах (quirk #32).
- Портал: прямоугольник → повторение со сдвигом → ступенчатая форма. Ступень = 40 px @1080p.
  Разрешены поворот 90/180 и отражения; заливка — любой цвет палитры или паттерн.

## 7. Форматы и safe-зоны

| Формат | Размер | fps | scale | margin | safe title |
|---|---|---|---|---|---|
| 1080p | 1920×1080 | 25 | 1.0 | 80 | 120 |
| 4K | 3840×2160 | 25 | 2.0 | 160 | 240 |
| story | 1080×1920 | 30 | 0.9 | 60 | 220 (UI-накладки сверху/снизу) |
| square | 1080×1080 | 30 | 0.8 | 60 | 100 |
| slide | 1280×720 | 30 | 0.667 | 40 | 60 |
| web | 1440×900 | 60 | 0.75 | 60 | 80 |

Все размеры шрифта и дистанции движения в токенах даны для 1080p и умножаются на `scale`.

## 8. Запрещено (стоп-лист)

Из `forbidden` в токенах — то, что мгновенно ломает бренд:

- отскок / пружина / elastic на брендовых элементах (на не-брендовом UI overshoot ≤ 2%);
- любые повороты, кроме шагов 90/180°; наклонный текст; крутящиеся логотипы;
- squash & stretch, «желе», idle wiggle, «дыхание»;
- тени, свечения, blur как стиль, лен-флеры, light leaks, зерно;
- градиенты на брендовых элементах; скругления; round caps;
- частицы, органический шум, «бумага», hand-drawn;
- italic, underline, mixed weight;
- зелёный body-текст, зелёные стрелки, зелёная заливка >30% content-кадра;
- эмодзи, сторонние иконки;
- 3D-облёты камеры (только линейный dolly / параллакс ≤ 3%);
- typewriter / letter-tumble на заголовках (только code/terminal).

Из старого house-style этого репозитория («GRID & RUPTURE», `reference/motion-art-direction.md`)
в Cloud.ru **не переносятся**: вермильон/электрик-синий, зерно, свечения, кинетический
overshoot заголовков. Переносятся: дисциплина сетки, асимметрия, контраст масштабов, stagger.

## 9. Чек-лист перед показом (каждая сцена)

- [ ] Один акцент в кадре; зелёного ≤ 10% площади, он появляется последним или как шторка.
- [ ] Все входы `enter`, выходы `exit` (короче на 30%), ни одного линейного физического движения.
- [ ] Ни одной дуги, поворота, отскока, wiggle; после посадки — полная неподвижность.
- [ ] Заголовок — line reveal по строкам, ≤ 3 строк, action title, без висячих предлогов.
- [ ] Цифры табличные, счётчик `count`, единица статична, тысячи через U+202F.
- [ ] Углы прямые, линии 2/4/6 px square caps, отступы кратны 10, всё кратно 2.
- [ ] Шрифт SB Sans Display (fallback Verdana) — прочитан обратно из AE / `document.fonts`.
- [ ] Тёмных сцен ≤ 40%; переходы — hard cut / block wipe / portal wipe, не dissolve.
- [ ] Логотип: оригинальный SVG, не искажён, зелёный/чёрный/белый, охранное поле = высота знака.
- [ ] Кадр выдержит «5-мерную критику» слайд-скилла: Philosophy / Hierarchy / Detail / Function / Innovation ≥ 4/5.
